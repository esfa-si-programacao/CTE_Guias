Ficha do equipamento
  • Inventário: INV-006 (Tuxedo Atlas XL) + INV-223 (NAS QNAP TVS-h874) + INV-224 (UPS APC) · Estúdio 4C
  • Estação AI (INV-006): TUXEDO Atlas XL Gen1 Intel · Chassis Fractal Design North XL (madeira/mesh) · Plataforma Intel Z790 · DDR5 · NVMe · GPU dedicada para IA/ML
  • Software Estação AI: TUXEDO OS / Ubuntu Linux · TUXEDO Control Center · CUDA / PyTorch / Ollama / JupyterLab / Docker
  • Servidor NAS (INV-223): QNAP TVS-h874-i7-32G · Intel Core i7-12700E (12 núcleos / 20 threads) · 32 GB DDR4 · 8 baías SATA + 2× M.2 PCIe Gen4 NVMe · 2× 2,5 GbE
  • Sistema NAS: QuTS hero (sistema de ficheiros ZFS com deduplicação, self-healing e snapshots) · Virtualization Station & Container Station
  • Proteção Elétrica (INV-224): UPS APC Smart-UPS SMT LCD RM SmartConnect (junto ao servidor)
